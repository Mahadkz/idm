# XDM production readiness

The release gate. XDM is production ready only when every item below is **Done** with the cited evidence, or explicitly marked out of scope with the reason. "Done" means implemented, tested by an automated check that runs in CI, and documented.

Status values: Done · In progress · Not started · Out of scope (reason).

Not built or not tested: cookies are not kept for the download itself (the daemon re-probes without them, so members-only videos can fail at download time), per-format headers are taken from the video format for both streams, GUI Add URL does not offer a format choice yet, Firefox is covered by the shared contract tests only (no real Firefox run for this change), Windows/macOS untested, live streams and DRM are excluded, and an occasional mid-download 403 from googlevideo was seen once and recovered by the re-probe |
